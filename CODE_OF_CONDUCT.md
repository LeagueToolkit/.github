# Code of Conduct

## The short version

Be decent to each other. We're here to reverse-engineer file formats and build tools, not to score
points.

## Expected behavior

- Assume good faith. Most disagreements here are about technical detail, not motives.
- Critique the code, the format finding, or the design - not the person who wrote it.
- Accept that "I'm not sure, here's what I observed" is a valid and valuable contribution. A lot
  of this work is guesswork against an undocumented binary; punishing uncertainty makes the
  guesses worse, not better.
- Respect maintainers' time. Search first, give complete reproductions, and accept "no" without
  relitigating it.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language of any kind
- Publishing someone's private information
- Sustained derailing, bad-faith argument, or demanding free labor
- Using these projects to distribute malware, or to build tools whose purpose is to harm players
  or Riot's services

## Reporting

Report problems privately to the org maintainers - open a private vulnerability report on
[LeagueToolkit/.github](https://github.com/LeagueToolkit/.github/security/advisories) if you have
no other channel, or contact a maintainer directly. Reports are handled confidentially.

Maintainers may remove comments, close issues, or ban contributors whose behavior violates this
document. We'll explain why when we do.

## Scope

Applies in all LeagueToolkit repositories - issues, pull requests, discussions, commits - and
anywhere someone is representing the org.
